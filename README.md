# Finance App - C# / Vue.js with Google Authentication\n\nA full-stack web application built with ASP.NET Core Web API backend and Vue.js frontend, featuring Google OAuth authentication and SQLite database.\n\n## Features\n\n- **Backend (ASP.NET Core 8 Web API)**\n  - Google OAuth 2.0 authentication\n  - JWT token-based authorization\n  - SQLite database with Entity Framework Core\n  - User management system\n  - RESTful API endpoints\n\n- **Frontend (Vue.js 3 + Vite)**\n  - Modern Vue 3 composition API\n  - Google Sign-In integration\n  - Responsive design\n  - Axios for API communication\n  - Vue Router for navigation\n\n## Project Structure\n\n```\n├── Backend/                 # ASP.NET Core Web API\n│   ├── Controllers/         # API controllers\n│   ├── Data/               # Database context\n│   ├── Models/             # Data models\n│   ├── Services/           # Business logic services\n│   ├── Program.cs          # Application entry point\n│   ├── appsettings.json    # Configuration\n│   └── Backend.csproj      # Project file\n├── Frontend/               # Vue.js application\n│   ├── src/\n│   │   ├── components/     # Vue components\n│   │   ├── router/         # Vue Router configuration\n│   │   ├── App.vue         # Main Vue component\n│   │   └── main.js         # Application entry point\n│   ├── public/             # Static assets\n│   ├── index.html          # HTML template\n│   ├── package.json        # Dependencies\n│   └── vite.config.js      # Vite configuration\n└── README.md               # This file\n```\n\n## Prerequisites\n\n- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)\n- [Node.js](https://nodejs.org/) (version 18 or later)\n- [Google Cloud Console](https://console.cloud.google.com/) account for OAuth setup\n\n## Setup Instructions\n\n### 1. Google OAuth Setup\n\n1. Go to the [Google Cloud Console](https://console.cloud.google.com/)\n2. Create a new project or select an existing one\n3. Enable the Google+ API\n4. Create credentials (OAuth 2.0 Client ID)\n5. Add authorized origins:\n   - `http://localhost:3000` (for development)\n6. Copy the Client ID\n\n### 2. Backend Configuration\n\n1. Navigate to the `Backend` directory\n2. Update `appsettings.json` and `appsettings.Development.json`:\n   ```json\n   {\n     \"Google\": {\n       \"ClientId\": \"YOUR_ACTUAL_GOOGLE_CLIENT_ID_HERE\"\n     }\n   }\n   ```\n3. Optionally update the JWT key for production:\n   ```json\n   {\n     \"Jwt\": {\n       \"Key\": \"your-secure-256-bit-key-here\"\n     }\n   }\n   ```\n\n### 3. Frontend Configuration\n\n1. Open `Frontend/src/App.vue`\n2. Replace `YOUR_GOOGLE_CLIENT_ID` with your actual Google Client ID:\n   ```javascript\n   const googleClientId = 'your-actual-google-client-id-here'\n   ```\n\n## Running the Application\n\n### Backend (ASP.NET Core)\n\n```bash\ncd Backend\ndotnet run\n```\n\nThe API will be available at `https://localhost:5001` or `http://localhost:5000`\n\n### Frontend (Vue.js)\n\n```bash\ncd Frontend\nnpm run dev\n```\n\nThe frontend will be available at `http://localhost:3000`\n\n## Development\n\n### Backend Development\n\n- The SQLite database (`finance.db`) will be created automatically on first run\n- API endpoints:\n  - `POST /api/auth/google` - Authenticate with Google\n  - `GET /api/auth/user` - Get current user info (requires JWT token)\n- Swagger documentation available at `/swagger` when running in development mode\n\n### Frontend Development\n\n- Hot reload is enabled by default with Vite\n- The frontend automatically proxies API requests to the backend\n- Google Sign-In button requires HTTPS in production\n\n## Building for Production\n\n### Backend\n\n```bash\ncd Backend\ndotnet publish -c Release -o ./publish\n```\n\n### Frontend\n\n```bash\ncd Frontend\nnpm run build\n```\n\nBuilt files will be in the `Frontend/dist` directory.\n\n## Security Notes\n\n- **Never commit your actual Google Client ID to version control**\n- Use environment variables for production secrets\n- Change the JWT key for production deployments\n- The current setup is for development - add proper HTTPS configuration for production\n\n## Next Steps\n\n- Add financial data models (transactions, accounts, budgets)\n- Implement CRUD operations for financial data\n- Add data visualization components\n- Implement user preferences and settings\n- Add export/import functionality\n- Implement proper error handling and logging
